# Chaitanya Gurav - Data Engineer Portfolio

A responsive data engineering portfolio built with HTML, CSS, and JavaScript.

## Features
- Modern dark data/cloud theme
- Responsive navigation
- Animated hero text
- Scroll reveal effects
- Project pipeline visualization
- Skills and AWS services section
- Contact links

## Run locally
Open `index.html` in a browser or use the VS Code Live Server extension.

## CI/CD Project Goal
This portfolio is designed to be deployed automatically to AWS through a CI/CD pipeline.
